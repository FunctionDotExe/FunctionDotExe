## Featured projects

**🩺 DermaVision** — melanoma detection from dermoscopic images
CNN pipeline trained on HAM10000 (10,015 images); ~0.90 AUC, 91% validation accuracy, with a fairness audit via Fairlearn.
`Python` `PyTorch` `TensorFlow` `CUDA`

**🎮 Decyp3r** — cross-platform micro-game engine
Six mini-games with streak tracking, live leaderboards, and anti-manipulation scoring, shipped to iOS, Android, and web. 95%+ crash-free sessions.
`React Native` `TypeScript` `Firebase`

**⚔️ Descent** — systems-driven game engine
Custom rendering, physics, and game logic built from scratch.
`C++` `Linear Algebra` `Graphics Programming`

**⚛️ Quantum ML research** — QNNs, VQE, and hybrid classical/quantum pipelines
`Qiskit` `PennyLane` `Cirq`
